# [EFX] impose

字幕スーパーを重ねる効果モジュールです。

スーパーインポーズできるパターンは大きく分けて3種類のモジュールで提供されます。モジュールの選択はラジオボタンで行います。

- calendar
- text
- loremipsum

また、共通項目として以下を設定可能です。

- フォント Font
- フォント効果 (Font ex)
- 前景色選択 Foreground
- 影 Shading
- 配置 Align

※ デスクトップが800x600の場合、設定画面が収まらなくなるので**globalで Cramped=Trueを設定**してください。

## パターンモジュール

### Calendar

指定した月のカレンダーを焼き付けます。

- Year/Month 基準になる年、月を指定します
- Num of month  並べる月数を指定します。1,2,3,6,9,12から選択できます。1～3の場合、Verticalフラグを設定していれば縦に、設定しなければ横に並べる形になります。6,9,12はそれぞれ3x2、3x3、3x4の配列になります。
- WeekEnd 土日をハーフトーンにします
- Holiday 祝日をハーフトーンにします。なお、祝日は固定日、ハッピーマンデー、春分秋分、振替休日、および国民の休日(オセロ休日)に対応しています。祝日の変更が発生したら、お手数ですがファイル先頭付近にある SP_HOLIDAY、HM_HOLIDAY を修正してください。
- Vertical  1～3カ月カレンダーの並びを縦並びにします。

### Text

任意のテキスト(2行)を指定位置に追加します。当初、(C)表記などの追加を想定していたのですが、飾り文字で焼き込む機能を追加しました。

- Line1/Line2 スーパーインポーズする文字列です。データが無い行は無視します。
- Layered  輪郭を繰り返し重ねます。繰り返し数は Stackで指定しますが、2以上を設定してください。
- HollowStack  中央に通常の文字列、下Stack行、上Upper行にアウトライン文字列を並べて書き込みます。言葉で説明するより実施してみてもらった方が判りやすいかと思います。なお、アウトライン文字列の色はshadingの指定職になります。

### Loremipsum

マルチラインのテキストを焼き込みます。ファイル指定をしない場合は、意味のないラテン語風テキスト(Lorem ipsum...)を用います。後述の行頭スペース表示有無指定と配置位置によって、左詰め・中央ぞろえ・右詰めを自動設定します。

- Width ラップ幅文字数です。外部テキストファイル(特にソースコードなど)を利用する時は大きめに。
- MaxL 最大行数を指定します。フォントが大きければ、この行数を表示しきれないのであまり気にしないでも良いです。
- Spaee(フラグ)  行頭の空白を表示する強制左詰めモードにするか、切り捨てるかを指定します。ソースコードなどの指定時はチェックを入れておくことをお勧めします。
- FileName 外部ファイル指定です。文字列ボックス横の[...]ボタンでファイル指定できます。また、先頭のチェックボックスをOFFにすると、外部ファイルではなく固定文字列を利用するようになります。

## 共通設定

### フォント

- フォント選択 指定ディレクトリ内のTruetypeフォントから、フォントファミリー|フォントフェイスの一覧を表示するので、クリックで選択。選択されたフォントが一覧下に表示される。
- ディレクトリ選択  [...]ボタンで任意のディレクトリを選択。[Sys]ボタンでシステムフォントディレクトリ(c:\Windows\Font) を選択する。ただし、[Sys]ではシステムにインストールされているフォントが全て表示されるのではなく、一部のフォントはAppDefaults配下のローカルフォントディレクトリを指定する必要がある。
- Size フォントサイズ
- Halftone  カレンダーの休日などに適用されるアルファ値
- Gradient(プルダウン)  行グラデーションタイプ。None/Linnear/Stripeを選択できる。ただし、Stripeはフォント最下ラインが欠けて見えてしまう場合がある
- boundary  Linearグラデーションの場合の開始位置。行の上からbounday%までは上端の色を維持する

### Foreground  前景色

前景タイプ(プルダウン) FG/BG/File/Plainから選択。FGはベース画像と同じ図柄だが、ShadingブロックのFG-Enbrightで指定した%で明度を調節可能。BGはholdで保持した背景画像を前景に適用する。Fileは任意の画像ファイルから指定。Plainは、ボタン押下で指定した色(Jitterで揺らぎを指定)を前景とする。

### Shading 影

文字の影に関して、ずれ幅、ぼかし半径、影強度、ならびに影色を指定する。

なおTextでHollowStackを選択した場合のHollow(アウトライン)色は影色になる。またHollowテキストには影が付かない。

### AlignText 配置

- Block Spaceカレンダーの日の間隔
- Line Space 行間隔
- X/Y-Pad  画面横・縦の余白幅。Windowsタスクバーを避けるための幅と考えても良い
- BlockAlign パターンを焼き込む位置を東西南北のプルダウンで指定。西/中/東で左詰め/中央寄せ/右詰めを自動選択する。LoremipsumモジュールでSpace=ONにした場合は強制左詰めになる。

### ボタン

- Test メイン画面に戻らず、プレビューの再表示を行う。文字入力パラメータの反映に利用
- Ok メイン側に炊き込み済イメージを渡す。本体側でSaveなり壁紙設定なりを実施すること
- Cancel 焼き込みを行わずにメイン画面に戻る
